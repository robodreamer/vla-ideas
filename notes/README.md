# Research Notes

This folder is a compact, repository-native knowledge base for VLA and embodied-AI references that inform future experiments. It is deliberately separate from experiment folders: notes capture claims, design implications, and sources; experiment folders capture runnable hypotheses and results.

## Conventions

- One note per primary source, named `YYYY-MM-DD-short-slug.md`.
- Start with an *evidence label* (`primary`, `secondary`, `vendor`, or `commentary`) and preserve important limitations.
- Distinguish *reported claims* from our own *implications* and *follow-up experiments*.
- Keep references canonical where possible and add a brief reason each source matters.
- Add every note to the index below.

## How agents should use this

Treat these notes as a starting point for research and experiment design—not as validated ground truth. Prefer the linked primary materials, reproduce claims on independent tasks/robots where possible, and write a new experiment folder only when there is a concrete, testable hypothesis.
